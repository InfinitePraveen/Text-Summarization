# Contributing to Text Summarization

Thank you for considering contributing to this project.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a virtual environment.
4. Install the dependencies.
5. Run the notebooks or Flask application.
6. Make your changes.
7. Test locally.
8. Open a pull request.

## Good Contribution Areas

- Improve notebook explanations
- Improve evaluation examples
- Improve the Flask interface
- Fix bugs
- Improve documentation
- Add responsible-use guidance
- Improve inference efficiency

## Code Style

Keep the code readable and straightforward. Prefer descriptive variable names and small functions.

## Pull Requests

Please explain what changed, why it changed, and how you tested it.

## Issues

Include your Python version, operating system, error message, and reproduction steps when reporting a problem.
